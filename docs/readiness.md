# How readiness and mastery are worked out (for parents)

BrightFox never gives a mark. It shows **about how ready** a kid is for a test, so you both know what to do
next. The number is an estimate, rounded to 5 %, and always shown as "about".

## Mastery of a skill

A topic is split into small skills (e.g. "country → nationality", "have got / has got"). Older topics
without skills count as one skill. For each skill:

| Evidence | Weight |
|---|---|
| ✏️ Practice: tasks right **on the first try, without the solution** (the latest try counts) | 40 % |
| 📝 Mock test points (when the test has a mock) | 25 % |
| 🏆 Champions League tasks, the same way | 15 % |
| 🃏 Flashcards marked "Znam" | 10 % |
| ✅ "I can" goals ticked | 10 % |

- Parts a topic doesn't have are left out and the rest re-weighted.
- Tasks not tried yet count as 0.
- A right answer older than 4 weeks counts half (knowledge fades).
- With only flashcards and ticks (no task tried), a skill is capped at 60 %: "Znam" needs shown work.

**Labels:** Znam 80 % and up · Skoraj 50–79 % · Še ne below 50 % · Ni začeto with nothing done.

## Readiness for a test

The average mastery of the skills on the test, each weighted by how many tasks it has. A skill nobody has
started counts as 0.

## The plan

Recomputed every day from the current mastery (nothing to "fall behind" on):

- Weakest skills first: read the notes, then flashcards, then practice until about 80 %, then the
  Champions League.
- Moje napake whenever some are due.
- The day before the test is light: Moje napake and a recap of the weakest skill.
- It follows the kid's usual study days and minutes (Family page). Today is always included.
- When there's too much left for the days remaining, you see "too little time".

## Moje napake

Every task that wasn't right first time comes back after 1, 3, 7 and 14 days. When it's right first time
four times in a row it is corrected for good (a ✅ the kid keeps). Three days before a test, every mistake
from the test's topics comes back.

## Gaps (Tests and gaps page)

- **Critical:** a skill on a test within 10 days below 50 %; a task wrong in two or more runs.
- **Attention:** a skill on a test at 50–79 %; Moje napake overdue; 3+ flashcards not known.
- **Minor:** "I can" goals not ticked although the practice went well; the solution was needed.

Each gap shows what was typed, so you see the actual mistake.
